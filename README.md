# ITBA-Sprint1-2
Hermanos Jota

Página web para una mueblería con catálogo de productos, carrito y formulario de contacto.


Hermanos Jota es una mueblería que vende productos de diseño clásico y artesanal, se enfoca en el uso de materiales sustentables. El sitio web tiene 4 páginas que son:

index.html: página principal, con presentación de la marca y productos destacados.
productos.html: catálogo completo de productos.
producto.html: detalle de un producto en particular.
contacto.html: formulario de contacto con nombre, email y mensaje con validación.

También hay un contador de carrito en el header que aparece en todas las páginas.

Tecnologías utilizadas
HTML
CSS
JavaScript 
JSON para los datos de los productos
Cómo correrlo

Es una página estática, así que alcanza con abrir el index.html en el navegador. Si da problemas por los módulos de JS, se puede levantar con un servidor local:

npx serve .
